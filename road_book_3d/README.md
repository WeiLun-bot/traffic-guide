# 道路交通標誌標線號誌設置參考指引｜3D 書本 HTML 初版（v2）

## 使用

1. 解壓縮 ZIP，保持 `index.html`、`pages/`、`navigation-config.json` 在同一資料夾。
2. 在 Chrome 或 Edge 中直接開啟 `index.html`，無需網路與伺服器。
3. 使用底部左右箭頭翻書、書本圖示回到封面，或從下拉選單跳轉；視角設定圖示可展開角度滑桿與「正面閱讀／觀看書口」。
4. 點擊左頁/右頁，或選放大鏡圖示檢視跨頁。鍵盤 ←/→ 可翻頁、Esc 離開放大。

## 原始設定還原

參考使用者提供的 `navigation-style.typ`：
- 頁面尺寸 A4 210×297 mm；頁籤寬 10.8 mm、高 25 mm、間隔 6 mm、頁首起點 54 mm。
- 四組頁籤在頁面上由上到下的起點：54、85、116、147 mm。
- 主題 M（褐灰）、G（橘棕）、C（紫灰），每組四階。第 2～4 色依 Typst 原始程式採 OKLab 明度差收斂 12%。
- 偶數 PDF 頁顯示左頁籤，奇數 PDF 頁顯示右頁籤；紙面直接使用 PDF 渲染，頁籤不重畫。
- 書口色帶只是每一段有印製頁籤的頁數在物理頁厚上的切面，用 541 頁中的實際章節頁數比例定位。色帶**不突出裁切線**。
- PDF 本檔未啟用 `print-bleed=true`，不加入印刷出血外凸部分。

## 範圍及後續調整

- 這份以 `output_1105.pdf` 製作，包含封面與指定的 12 組跨頁（24 個內頁），並非 541 頁完整電子書。
- 每個內頁是 WebP 圖片，PDF 頁中的現成 SVG 路圖不具備可獨立選取放大的向量功能；若需真正 SVG 無損放大，必須另接原始 SVG 素材到頁面互動圖框中。
- 每頁圖片均保留原始側邊印刷色籤。畫面中的 3D 紙厚、硬殼和翻頁採 CSS 3D / JavaScript 模擬，非外部 CAD 或 WebGL 網格檔。
- 可在 `navigation-config.json` 檢視頁籤原始尺寸、各色系及章節起訖；需更換圖頁時，同步修改 `index.html` 末尾 DATA 對應 `spreads` 與 `pages/` 圖檔。


## 第一場簡報內展示

第一場簡報「成果與運用」最後的書籍展示以 `index.html?embed=1` 載入，移除頁面標題並放大書本。桌面將操作與視角調整移到右側；窄螢幕保留底部操作列。保留翻頁、章節跳轉、旋轉與放大功能，也可從簡報右上方選擇「全螢幕展示」或「獨立開啟」。簡報的下一頁／上一頁按鈕及方向鍵、PageDown／PageUp、空白鍵會先翻書；最後一組跨頁再按下一頁才離開，封面按上一頁返回前一張簡報。翻頁期間的重複操作會忽略，翻書保留視角與同一個書本畫面。直接開啟本資料夾的 `index.html` 保留底部操作列與書名標題。

## output_1105 指定展示頁

頁碼均指 PDF 實際頁序，並非頁面下方印刷頁碼：

4–5、64–65、94–95、102–103、134–135、142–143、318–319、378–379、502–503、518–519、530–531、532–533。

封面取 PDF 第 1 頁。PDF 第 502、530 頁是原檔中的空白左頁，保留原樣以維持跨頁方向。每頁以 200 DPI 轉為 WebP；原 PDF 不需放入網站。`navigation-config.json` 記錄來源雜湊、實際頁序與每張展示圖片的尺寸及雜湊。

更新圖片可執行 `node tools/render-book-pages.cjs <PDF路徑> --config=road_book_3d/navigation-config.json --dpi=200`；工具會先備份既有展示頁，並將逐頁驗證清單與總覽圖存到 `exports/book-page-renders/`。
