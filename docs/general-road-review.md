# 一般道路情境檢視紀錄

檢查日期：2026-11-08。以讀取時已儲存的教材建立測試副本，保留圖片替換、初始視角及圖片順序。

## 結果

18 個案例、220 頁（含 131 項條文與設施解說）已完成檢查。1920×1080、1536×864、1024×768、390×844 四種尺寸共 880 次逐頁檢查，未發現圖片載入失敗、失效頁面連結或水平溢出。150 份目前使用的圖片皆可載入，包括 5 份已替換素材。

功能驗證涵蓋情境與章節導覽、比較頁返回原頁、表格與參照視窗、現況照片、圖片顯示選單、獨立初始視角、縮放拖曳與旋轉、打亮框、內容增刪排序、復原／重做、儲存重新載入、純瀏覽模式、延遲載入及失敗重試。61 項單元測試及 13 組既有瀏覽器測試套件通過；另新增一組保留使用者設定的全頁檢查。

本次未發現新的功能故障。先前比較頁按鈕誤觸換圖的修正，已在 G1-06、G3-02、G3-04 的左右六張圖重新驗證。

## 後續操作補查

後續補查發現，原先巡檢未涵蓋「選單最後一項是否被圖片框裁切」及「套用視角前後的實際位置差」。這兩項已修正，新增測試會實際點選浮動選單，並在擷取旋轉圖面的當下與動畫時間後比較完整視框和繪圖矩陣；另驗證視角／框選參數沿用及小結排序。操作方式見 [視覺編輯器說明](visual-editor.md#初始畫面打亮放大範圍與參數沿用)。

- 新增 `tests/general-road-audit-browser.cjs`；以現行頁面清單巡檢，保留使用者的圖片視角與順序。

## 重跑方式

先執行 `node tools/prepare-github-pages.cjs --quiet`，再執行：

```powershell
node tests/visual-editor-browser.cjs --general-audit-only
node tests/visual-editor-browser.cjs --comparison-image-controls-only
node tests/visual-editor-browser.cjs --general-details-only
```

全頁檢查的 `page-audit.json`、`assets.json` 與發現問題時的截圖，預設輸出至 `tests/artifacts/visual-editor/`；可用 `VISUAL_EDITOR_ARTIFACTS` 指定另一個測試目錄。本次檢查證據保存在 `tests/artifacts/general-audit-20261108*`。
